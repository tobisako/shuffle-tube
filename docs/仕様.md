## 1. 目的

YouTube 動画の **「どこからどこまで」の数秒〜数分間だけ** を 1 件として並べ、連続再生するプレイリストを作る。
例: 「この Shorts の 0:39 から 10 秒間」が 1 件。1 本の動画から 2 か所・3 か所と別々の区間を登録できる。
区間を指定しなければ動画まるごと 1 件としても登録できる。macOS デスクトップアプリ。

## 4. 機能

### 4.1 クリップとプレイリスト
- **クリップ** = 動画 ID + 開始秒 + 終了秒（終了なし = 最後まで）+ メモ（任意）
- 同じ動画から複数のクリップを登録できる（開始・終了が完全に同じものだけ重複として弾く）
- 複数プレイリストの作成 / 名前変更 / 削除 / 全削除
- クリップの並べ替え（ドラッグ＆ドロップ、↑↓）、削除

### 4.2 クリップの追加（区間の設定は全て GUI）

**A. URL 貼り付け** — 入力欄に URL を貼って「追加」。動画まるごとのクリップになる。

| 入力 | 動作 |
|---|---|
| `youtube.com/watch?v=ID` / `youtube.com/shorts/ID` / `youtu.be/ID` / embed / live / 動画 ID | 動画を追加 |
| URL に `t=39` / `start=39` / `end=49` | 開始・終了として取り込む |
| `youtube.com/playlist?list=…` | 再生リスト内の動画をまとめて取り込み（最大 200 本） |

スペース・改行・カンマ区切りで複数同時に追加できる。

**B. 再生しながらマーク（メイン導線）** — 操作バーの「⏺ 開始点」「⏹ 終了点」で現在位置を取り込み、
「＋ この区間をクリップとして追加」で、今の動画の新しいクリップとして再生中クリップの直後に挿入。

**C. 区間エディタ（行の ✎）** — タイムライン上の 2 つのつまみ（開始 / 終了）をドラッグ。
- 「現在位置」ボタン、−1s / −0.1 / +0.1 / +1s ボタン、「最後まで」チェック
- **拡大縮小はホイール**: トラック上にカーソルがあるときだけ、ホイール上下でカーソル位置の時刻を固定したまま連続的に拡大縮小（最小 1 秒幅〜動画長の 4 倍）。左右スクロールで表示範囲を移動。ボタンは無い
- 動画の長さより広く表示したとき、0:00 より左と最後より右は斜線の背景で描き、動画の全体範囲が分かるようにする。目盛り（時刻）を自動間隔で表示
- **編集中は再生を止めない**。エディタを開くと再生が始まり、区間の終わりに達したら頭に戻って繰り返し再生し続ける（範囲を変えると次の周回から反映）
- 「▶ 頭から再生」で区間の頭からやり直す
- 変更は即時反映（保存ボタンなし）。止まっているときにつまみをドラッグすると、その位置のフレームを表示する
- 行の ＋ で「同じ動画から新しい区間」を作ってエディタを開く（取り消しで削除して元のクリップへ戻る）
- メモ欄だけは文字入力（数値の入力欄は無い）

追加後、タイトル・投稿者名・サムネイル・動画の長さを自動取得。取得失敗時は再生時にプレーヤーから補完。
YouTube 内のキーワード検索は対象外。

### 4.3 再生
- クリックで再生。**開始秒から再生し、終了秒に達したら自動で次のクリップへ**
- 次のクリップが同じ動画なら再読み込みせず、位置だけ移動する
- 再生 / 一時停止、前へ、次へ
- シャッフル（1 周するまで同じクリップを繰り返さない）
- リピート: オフ → 全曲 → 1 曲（1 曲 = その区間を繰り返す）
- 「前へ」は区間の開始から 3 秒以降なら区間の頭へ戻る
- 埋め込み禁止・削除済み動画はエラー表示して自動スキップ
- 終了時の再生クリップを記憶し、次回起動時に頭出し（自動再生はしない）

### 4.4 追加機能（設定画面で個別に ON / OFF）

| 機能 | 内容 | 初期値 |
|---|---|---|
| メディアキー | F7 / F8 / F9（前 / 再生停止 / 次）。アプリが背面でも効く。**macOS のアクセシビリティ許可が必要**（設定画面から許可を求められる） | ON |
| 常に最前面 | ウィンドウを他のアプリより前に表示 | OFF |
| ミニプレーヤー | 小窓モード。ボタンと Command + Shift + M で切替 | OFF |
| 音量・再生速度の記憶 | 終了時の音量・速度を次回起動時に復元 | ON |
| 視聴履歴 | 再生したクリップ（動画＋区間）を日時付きで記録（最大 500 件）。「履歴」タブから再生・削除・全消去 | ON |
| スリープ防止 | 再生中は Mac をスリープ・画面オフさせない（一時停止で解除） | ON |

### 4.7 ライブラリ（動画の保管庫）

- サイドバー最上段の「📚 ライブラリ」を選ぶと、メイン領域がライブラリ一覧に切り替わる（Command + Shift + L）
- **URL を貼って「保存」**するとライブラリに溜まる（動画 ID で重複排除）。再生リスト URL なら全動画を保存
- プレイリスト表示中に URL を貼って追加した動画も、自動的にライブラリに入る。既存プレイリストの動画は初回起動時に取り込む
- 一覧の各行: サムネイル・長さ・タイトル・投稿者・使用クリップ数・保存日・メモ（クリックで編集）
- 絞り込み欄（タイトル・投稿者・メモ）、追加先プレイリストの選択
- 行のクリック / ▶ で**プレビュー再生**。再生しながら「⏺ 開始点 / ⏹ 終了点 / ＋ この区間をクリップとして追加」で追加先プレイリストに区間を登録する
- ＋ で動画まるごと追加先プレイリストへ（区間はプレイリスト側の ✎ で設定）。≡ で追加先プレイリストを開く。✕ でライブラリから削除（プレイリストのクリップは残る）
- 「▶ 全て再生」でライブラリ全体を 1 つのプレイリストとして連続再生（シャッフル・リピートも効く）
- 保存先: `library.json`

### 4.8 スマホブラウザ版（LAN）

- 設定の「スマホ連携（同じ Wi-Fi に公開）」を ON にすると、Mac の `0.0.0.0:8787`（使用中なら +1 して探す）で HTTP サーバーが起動する。初期は OFF
- 設定画面に URL（例 `http://192.168.1.23:8787/`）と QR コードを表示。スマホの Chrome で開く
- スマホでは同じ React 画面がスマホ向けレイアウトで動く: プレーヤーは上部に固定、下部タブ（プレイリスト / ライブラリ / 履歴 / 設定）、プレイリストはプルダウンで切替
- **再生はスマホ自身**（YouTube 埋め込み）。区間の編集・マーク・ライブラリ操作もスマホでできる。区間エディタは 2 本指ピンチで拡大縮小、横ドラッグで移動、タップでシーク
- **データは Mac が正**: プレイリスト・ライブラリ・履歴は `/api/playlists` 等で読み書きし、変更は SSE（`/api/events`）で全端末に即時配信。自分の変更の echo はクライアント ID で無視
- 端末ごとの設定（シャッフル・リピート・選択中リスト・音量・最後の再生位置・履歴記録・画面ロック防止）はスマホの localStorage
- スマホ側の「画面ロック防止」は Wake Lock API。書き出しはダウンロード、読み込みはファイル選択
- 認証は無し（同じ LAN 内のみ）。macOS のファイアウォールが初回に確認を出すことがある

### 4.9 MP4 書き出し（未実装・方針のみ確定）

- 方式 A: yt-dlp で元動画を取得（キャッシュ）→ ffmpeg で各クリップの区間を切り出し → 1 本の mp4 に結合
- 書き出す対象はクリップごとのチェックで選ぶ
- **画面比は統一しない**（2026-09-11 指示「統一するな。まぜろ。」）。縦動画・横動画をそれぞれの比率のまま混在させる。実装時に混在の具体方法（同一キャンバス内で比率を保つ等）を確認する
- yt-dlp は未導入（`brew install yt-dlp` が必要）。実装は「いったん停止」の指示で保留中

### 4.10 Android アプリ版（Capacitor、野良 APK）

- 今の React 画面を Capacitor で Android の WebView アプリに包む。appId `jp.tobisako.youtubeplaylist`、アプリ名「ShuffleTube（旧名 ShuffleTube）」
- **スマホ内のデータが正**: プレイリスト・ライブラリ・履歴・設定はアプリ内のファイル（Capacitor Filesystem、`Directory.Data`）に JSON で保存。Mac が無くても全機能が動く
- タイトル・投稿者・長さの取得はアプリ内のネイティブ HTTP（CapacitorHttp、CORS の制約なし）で oEmbed と視聴ページから取る
- **Mac との同期は明示操作のみ**: 設定に Mac の URL（例 `http://192.168.1.23:8787/`）を保存し、「Mac から取り込む」（Mac のプレイリスト・ライブラリ・履歴でスマホ側を置き換え）と「Mac へ送る」（逆）の 2 ボタン。自動マージはしない
- 再生は WebView 内の YouTube 埋め込み。自動再生と区間終了後の自動遷移のため、WebView の「メディア再生にユーザー操作を要求」を無効化する。画面を消す・アプリを裏に回すと再生は止まる（YouTube 側の仕様）
- 再生中は画面を消灯させない（keep-awake プラグイン）
- 書き出しは端末の共有シート（JSON ファイル）、読み込みはファイル選択
- ビルド: この Mac の JDK 21 + Android SDK（コマンドラインツール）で `./gradlew assembleRelease`。個人用キーストアで署名した release APK を `dist/` に置き、Mac の LAN サーバーの `/app.apk` からもダウンロードできるようにする
- インストール: 開発者モード不要。APK を開くアプリに「提供元不明のアプリ」の許可を一度与える
- テストはこの Mac 上の Android エミュレータ（arm64 システムイメージ）で行う

### 4.6 データ
- `~/Library/Application Support/ShuffleTube/（Windows は %APPDATA%\\ShuffleTube\\）` に `playlists.json` / `library.json` / `settings.json` / `history.json`

## 5. やらないこと
- 動画・音声のダウンロード、オフライン再生
- 広告の除去
- YouTube アカウント連携、YouTube 内検索
- Apple Developer ID による署名・公証
- Windows / Linux ビルド

## 6. 技術メモ
- renderer は `file://` で読み込まない（YouTube 埋め込みが Referer 無しでエラー 153）。本番は main 内の `127.0.0.1` HTTP サーバーから配信し、CSP ヘッダも付ける
- main ↔ renderer は contextBridge + IPC（`nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`）
- 区間再生は renderer 側で 100 ms ごとに現在位置を監視。`endSeconds` はシーク後に無効になるため使わない
- 音量・速度は再生開始のたびに再適用。動画の読み込み直前に音量を当て、再生開始イベントまで一時ミュートして最大音量が漏れないようにする。音量の保存は 1 秒おきに 2 回同じ値のときだけ
- 動画の長さは視聴ページ HTML の `lengthSeconds`（ベストエフォート）。取れなければ再生時に `getDuration()`
- スリープ防止は `powerSaveBlocker('prevent-display-sleep')` を再生中のみ
- メディアキーは `globalShortcut`。macOS ではアクセシビリティ許可が無いと登録に失敗する
